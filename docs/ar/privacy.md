# الخصوصية والتعامل مع البيانات (الوضع التقني — بانتظار المراجعة القانونية)

هذه الوثيقة تصف ما يفعله النظام تقنيًا فقط، وليست إفادة امتثال قانوني.
راجع `docs/NEEDS_FROM_ME.md` بخصوص المراجعة القانونية المطلوبة، خصوصًا
فيما يتعلق بقانون حماية البيانات الشخصية الاتحادي الإماراتي رقم ٤٥
لسنة ٢٠٢١.

## بيانات الطفل المخزّنة

الاسم الأول، الضمير، اسم الفصل، اللغة المفضلة، وإعدادات شخصية رمزية
هيكلية (لا صور فوتوغرافية أبدًا).

## الموافقة

كل قصة تتطلب موافقة صريحة وقابلة للسحب من ولي الأمر، عبر رابط عام لا
يتطلب حسابًا. التخصيص باستخدام صور حقيقية غير متاح إلا بعد تفعيل صريح
ومراجعة قانونية كاملة.

## عزل البيانات بين المؤسسات

مطبّق عبر سياسات أمان مستوى الصف في قاعدة البيانات (RLS)، ومُثبت باختبارات
آلية حقيقية.

## التخزين

جميع الملفات المولَّدة في حاوية تخزين خاصة، ولا تُصدر أي روابط عامة؛ كل
رابط يصل للمتصفح موقّع ومحدود الصلاحية لعشر دقائق فقط.

## الاحتفاظ والحذف

قابل للتخصيص لكل مؤسسة (افتراضيًا ٧٣٠ يومًا). حذف الطفل يحذف تلقائيًا كل
قصصه وملفاته المرتبطة.

## ما لم يُنجز بعد

تقييم أثر حماية البيانات الرسمي، تأكيد مكان إقامة البيانات، تحليل النقل
عبر الحدود، واتفاقية مستوى خدمة نهائية للاحتفاظ والحذف — جميعها معلّقة
حتى مراجعة قانونية مؤهلة.
